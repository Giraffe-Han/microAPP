# 部署指南 (Deployment Guide)

本项目已整合为 **前后端一体化包**，可以直接部署到 Linux 服务器。

## 1. 项目结构

```
低空综合服务平台/
├── backend/                 # 后端服务
│   ├── index.js             # 服务入口
│   ├── storage.js           # 数据存储层
│   ├── platformAuth.js      # SSO 认证
│   ├── public/              # 静态资源 & 前端构建文件
│   │   ├── assets/          # 前端 JS/CSS
│   │   ├── uploads/         # 用户上传文件
│   │   └── index.html       # 前端入口
│   ├── db/                  # 数据库相关
│   └── *.json               # 业务数据文件
│
├── frontend/                # 前端源码
│   └── h5/                  # Vue3 + Vite 项目
│
├── sql/                     # 数据库脚本
└── docs/                    # 项目文档
```

## 2. 本地开发

### 启动后端服务

```bash
cd backend
npm install
npm run dev
```

后端服务地址: `http://localhost:3000`

### 启动前端开发服务

```bash
cd frontend/h5
npm install
npm run dev
```

前端访问地址: `http://localhost:5173`

## 3. 服务器环境要求

确保目标 Linux 服务器安装了：
- **Node.js** (推荐 v16 或更高)
- **PM2** (进程守护工具): `npm install -g pm2`
- **Nginx** (反向代理 Web 服务器)

## 4. 生产部署步骤

### 第一步：构建前端

```bash
cd frontend/h5
npm install
npm run build
```

构建完成后，将 `frontend/h5/dist/` 目录内容复制到 `backend/public/`。

### 第二步：上传文件

将整个 `backend` 文件夹上传到服务器目录，例如 `/data/low-altitude/backend`。

### 第三步：安装依赖

```bash
cd /data/low-altitude/backend
npm install --production
```

### 第四步：启动服务

使用 PM2 启动服务（指定端口，例如 8090）：

```bash
# 如果有旧服务先删除
pm2 delete low-altitude-server

# 启动新服务
PORT=8090 pm2 start index.js --name "low-altitude-server"

# 检查是否成功启动
pm2 list
```

### 第五步：Nginx 配置

配置 Nginx 将域名流量转发到 8090 端口：

```nginx
server {
    listen 80;
    server_name microapp.wzdkfx.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name microapp.wzdkfx.com;

    ssl_certificate /etc/nginx/cert/wzdkfx.com.pem;
    ssl_certificate_key /etc/nginx/cert/wzdkfx.com.key;

    # 静态文件缓存优化
    location /assets/ {
        root /data/low-altitude/backend/public;
        expires 30d;
    }

    # 所有请求转发给 Node 服务
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

重启 Nginx：

```bash
nginx -t
systemctl reload nginx
```

## 5. 常见问题排查

### 启动报错 `Error: listen EADDRINUSE`
- 端口被占用，修改启动命令中的端口：`PORT=8091`

### 图片无法加载 (404 Not Found)
- 检查 `backend/public/uploads` 目录是否存在且有文件
- 检查 Nginx 代理配置是否正确指向 Node 服务端口

### 上传文件失败 (Permission denied)
- 检查目录权限：`chmod -R 755 /data/low-altitude/backend/public/uploads`

### SSO 登录失败
- 检查 `platformAuth.js` 中的配置
- 确认畅行温州平台的接口地址和密钥正确

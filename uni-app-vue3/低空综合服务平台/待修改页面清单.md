## 🔧 修改步骤（每个页面）

### 第1步：添加import语句

在 `<script setup>` 顶部添加：

```vue
import TabBar from '@/components/TabBar.vue'
```

### 第2步：在template末尾添加TabBar

在页面容器的 `</view>` 之前添加：

```vue
<!-- 自定义TabBar -->
<TabBar :current="X" />
```

**注意**：X为对应的current值（0, 1, 2, 3）

### 第3步：确保页面有底部padding

检查页面样式中是否有：

```css
.page-container {
  padding-bottom: 60px;
}
```

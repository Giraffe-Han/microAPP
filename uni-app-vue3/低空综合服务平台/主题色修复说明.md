## 💡 技术说明

### uni-app TabBar配置

#### 颜色配置项
```json
"tabBar": {
  "color": "#969799",           // 未选中tab文字颜色
  "selectedColor": "#667eea",   // 选中tab文字颜色 ⭐
  "backgroundColor": "#ffffff", // tab背景色
  "borderStyle": "white"        // tab边框颜色
}
```

#### 图标配置
```json
{
  "iconPath": "static/icon-normal.png",      // 未选中图标
  "selectedIconPath": "static/icon-active.png"  // 选中图标
}
```

**注意**：
- iconPath 和 selectedIconPath 分别对应未选中和选中状态的图标
- 可以使用不同颜色的图标来匹配主题色
- 建议准备紫色版本的选中图标

### uni-app 导航栏配置

#### 全局配置（globalStyle）
```json
"globalStyle": {
  "navigationBarBackgroundColor": "#667eea",  // 导航栏背景色 ⭐
  "navigationBarTextStyle": "white",          // 导航栏文字颜色（black/white）
  "navigationBarTitleText": "标题",          // 导航栏标题
  "backgroundColor": "#f5f5f5"                // 窗口背景色
}
```

#### 页面单独配置（pages[].style）
```json
{
  "path": "pages/home/index",
  "style": {
    "navigationBarBackgroundColor": "#667eea",  // 覆盖全局配置
    "navigationBarTitleText": "服务大厅"
  }
}
```

## 🔍 常见问题

### Q1: 修改后颜色没有变化？
**A:** 
1. 重新编译项目
2. 清除缓存：开发者工具 → 清缓存 → 全部清除
3. 重启开发者工具

### Q2: Tab图标颜色也需要改吗？
**A:** 
- 如果使用纯色图标，建议准备紫色版本
- 如果使用彩色图标，保持原样即可
- 当前配置使用的是logo.png，建议替换为合适的Tab图标

### Q3: 不同页面的导航栏颜色可以不同吗？
**A:** 
- 可以！在pages.json中为每个页面单独配置
- 页面级配置会覆盖全局配置（globalStyle）

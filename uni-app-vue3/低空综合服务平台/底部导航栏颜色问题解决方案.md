# 底部导航栏颜色问题解决方案

## 📋 问题描述
- pages.json 中已配置 `"selectedColor": "#000000"`（黑色）
- 重新编译后底部Tab仍然显示为**绿色**
- 这是微信开发者工具的**缓存问题**

---

## ✅ 解决方案（按顺序尝试）

### 方案1：清除微信开发者工具缓存（推荐）⭐

#### 步骤：
1. **打开微信开发者工具**
2. **菜单栏** → **工具** → **清除缓存**
3. **选择"全部清除"** 
   - ✅ 清除文件缓存
   - ✅ 清除网络缓存
   - ✅ 清除Storage缓存
4. **点击"确定"**
5. **等待清除完成**
6. **点击"编译"按钮重新编译**
7. **查看效果**

---

### 方案2：删除编译输出目录

#### 步骤：
1. **关闭微信开发者工具**
2. **打开项目目录**：
   ```
   uni-app-vue3/低空综合服务平台/
   ```
3. **删除 `unpackage` 文件夹**
   ```
   删除：unpackage/dist/dev/mp-weixin/
   ```
4. **重新打开微信开发者工具**
5. **重新编译项目**
6. **查看效果**

#### Windows 命令行删除：
```powershell
cd "uni-app-vue3\低空综合服务平台"
rmdir /s /q unpackage
```

---

### 方案3：重启微信开发者工具

#### 步骤：
1. **完全关闭微信开发者工具**（不是最小化）
2. **等待5秒**
3. **重新打开微信开发者工具**
4. **重新导入项目**
5. **编译运行**
6. **查看效果**

---

### 方案4：手动修改project.config.json（高级）

#### 步骤：
1. **打开文件**：`uni-app-vue3/低空综合服务平台/project.config.json`
2. **查找或添加以下配置**：
   ```json
   {
     "setting": {
       "useCompilerPlugins": false
     }
   }
   ```
3. **保存文件**
4. **重启微信开发者工具**
5. **重新编译**

---

### 方案5：检查小程序基础库版本

#### 步骤：
1. **微信开发者工具右上角** → **详情** → **本地设置**
2. **查看"调试基础库版本"**
3. **建议使用 2.30.0 或更高版本**
4. **如果版本过低，升级基础库版本**
5. **重新编译**

## 💡 为什么会出现绿色？

### 原因分析：
1. **微信小程序默认主题色是绿色**（#07c160）
2. 当配置未生效时，会使用默认的绿色
3. **缓存导致旧配置仍在使用**
4. 开发者工具读取了旧的编译结果

### 缓存位置：
- 微信开发者工具缓存目录
- `unpackage/dist/dev/mp-weixin/` 编译输出
- 浏览器缓存（如果使用H5预览）

---

```
微信开发者工具 → 工具 → 清除缓存 → 全部清除
```



低空综合服务平台（以下简称"本平台"）由【温州低空经济发展有限公司】（以下简称"我们"）运营管理。本隐私政策（以下简称"本政策"）旨在向企业用户和个人用户（统称"用户"或"您"）说明我们在您使用本平台浏览低空综合服务信息、提交与管理服务申请、报名低空研学与飞手培训、参与赛事预注册、办理无人机物流/医疗配送及销售租赁维修金融保险等过程中，处理个人信息的方式。

【特别提示】请您在使用本平台前认真阅读并充分理解本政策的全部内容，特别是以【特别提示】标注及涉及敏感个人信息、未成年人信息、设备权限、共享与您的权利等条款。如您对本政策有任何疑问，请通过本政策载明的方式进行咨询。您使用或在我们更新本政策后继续使用我们的产品或服务，即意味着您同意本政策（含更新版本）内容，并同意我们按照本政策处理个人信息。如您不同意本政策或其中任何条款，您可以选择停止注册或停止使用本平台，同时我们将因无法获取必要信息而无法再为您提供相关服务。

本政策仅适用于本平台提供的产品或服务，不适用于任何由本平台之外的其他平台（含第三方服务方）提供的产品、服务、网站或其他内容。

您利用本平台进行个人信息等数据的上传、下载、发布、分发、存储等活动，应当确保数据处理活动的合法性。如上述数据中涉及您以外的其他个人信息主体的个人信息，您应当确保该等处理符合法律规定，且在处理前已依法向相关个人告知处理的个人信息种类、目的、方式等事项，并已依法取得个人的同意。若因您未取得相应授权导致本平台受到损失的，本平台有权向您追偿，您应赔偿本平台全部损失（包括但不限于为维护自身权益支出的差旅费、律师费、诉讼费等）。

一、定义
个人信息：是指以电子或者其他方式记录的与已识别或可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
敏感个人信息：是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，如身份证件号码、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。
个人信息处理者：是指在个人信息处理活动中自主决定处理目的、处理方式的组织、个人。
个人信息的处理：包括个人信息的收集、存储、使用、加工、传输、提供、公开、删除等。
匿名化：是指个人信息经过处理无法识别特定自然人且不能复原的过程。
第三方服务方：指实际提供或参与提供相关服务的第三方主体，包括但不限于培训机构（如浙江御风航空科技有限公司）、医疗机构、检验机构、药房、保险机构、维修与租赁服务方、赛事组织方等。

二、我们如何收集、使用个人信息及相关数据
我们仅会出于本政策所述目的，收集和使用为实现相应功能所必需的个人信息。若我们收集、使用的信息涉及敏感个人信息，我们将以【特别提示】方式显著告知并单独取得您的同意。

（一）注册与登录
1. 账号密码注册：您注册本平台账号时，需要提供手机号码、登录密码及图形验证码，姓名（选填）。密码经加密（哈希）后存储，我们无法查看明文。如果您不同意提供上述必要信息，将无法完成注册。
2. 账号密码登录：您登录时需提供账号（手机号/用户名）与密码，用于身份验证。
3. 微信登录（如开放，在您授权后）：我们会收集您的微信开放标识（OpenID）及您授权提供的微信绑定手机号，用于创建或登录账号。
4. 畅行温州平台单点登录（SSO，在您授权下）：我们接收该平台传递的必要身份标识信息，用于自动登录。
5. 我们已预留手机号短信验证码功能，如启用将用于身份校验与安全防护。

（二）实名认证
在您使用医疗配送、飞手培训、赛事预注册等需实名核验的服务前，为验证您的真实身份，本平台需要您提供：真实姓名、身份证号码（及按规则要求的证件信息、联系方式）。展示时我们将对姓名与身份证号进行脱敏处理。身份证件号码属于敏感个人信息，我们仅在核验身份所必需的范围内处理。如果您不同意提供上述信息，将无法完成实名认证及使用相应服务。
【如为企业用户经办人，为完成企业实名认证，可能需要您提供：企业营业执照、法定代表人身份信息、企业业务资质、公司介绍、授权委托书、经办人姓名与联系方式等。】

（三）服务申请与办理（低空综合服务）
当您就无人机物流、外卖配送、政务服务、托管、吊运、表演、租赁、销售、维修、金融保险等服务提交申请时，根据服务类型不同，我们可能收集：联系人姓名、联系电话、性别、证件号码、出生日期、联系/收发货地址、申请事由及相关业务信息，用于受理、审核、履约及与第三方服务方对接。如果您不同意提供相应必要信息，将无法完成该服务申请。

（四）低空研学报名（含未成年人）
低空研学课程面向青少年（如6-16岁）及亲子家庭。报名时我们可能收集：学员姓名、年龄/出生日期、性别、监护人姓名与联系方式、紧急联系人、健康与安全注意事项等，用于报名受理、保险购买、安全管理与结业证书发放。涉及不满十四周岁未成年人个人信息的，属于敏感个人信息，须由父母或其他监护人同意并按本政策第七条处理。

（五）飞手培训报名（CAAC）
飞手培训及执照考试由具备资质的第三方培训机构组织实施。报名时我们或培训机构可能收集：姓名、身份证件号码、出生日期、性别、联系方式、学历、身体条件（如视力、色觉、健康状况）、有无犯罪记录声明、报考执照种类、证件照片等，用于报名资格审核、培训组织与执照申报。上述信息中包含敏感个人信息，我们将仅在报名与取证所必需范围内处理。

（六）赛事（DSL）预注册
裁判员、教练员、运动员及俱乐部在线注册时，我们可能收集：姓名、性别、身份证件号码、出生日期、联系电话、所属单位/俱乐部、组别、证件照片及相关资质信息，用于注册审核与赛事组织管理。

（七）医疗配送服务
医疗配送涉及血液制品、检验样本、药品制剂、医疗器械等物资的即时配送，须实名下单。我们可能收集：下单人真实姓名、联系电话、收发件机构与联系人、配送地址与物资信息、订单状态等，用于订单受理、配送调度与全程跟踪。若相关服务涉及医疗健康类敏感个人信息，我们将以【特别提示】显著告知并单独取得您的同意；相关诊疗、检验、药品质量等责任由相应医疗机构/服务方承担。

（八）交易类服务（销售、租赁、维修、金融保险等）
当您使用无人机销售/以旧换新、租赁、维修、金融保险等服务时，我们可能收集：交易与订单信息、设备信息、投保/理赔所需的身份与联系信息、支付相关信息等，用于交易撮合、履约与售后。涉及金融账户等敏感个人信息的，我们将单独告知并取得您的同意。

（九）客户服务、安全保障与日志
为处理您的咨询、投诉、账号找回/注销申请，我们可能收集您主动提供的联系方式与相关说明信息。为保障账号与系统安全，我们可能收集设备信息、日志信息（如访问时间、操作记录、IP 地址）。我们采用防泄漏、反爬虫等技术保障信息安全，并限制频繁查询等异常操作，以防账号密码泄露或身份被冒用。

（十）委托处理与第三方服务方
我们向您提供的某些功能可能由我们委托的其他方（"受托方"）或第三方服务方提供（如培训机构、医疗/检验机构、保险机构、维修租赁方、赛事组织方、技术服务提供商等）。为完成服务申请与履约，我们可能向其提供办理该服务所必需的信息。我们会按照法律规定对受托方处理个人信息提出要求，并对其个人信息处理活动进行监督。

（十一）征得授权同意的例外
根据相关法律法规，在下列情形下收集、使用个人信息无需征得您的授权同意：
1. 为履行法定职责或法定义务所必需；
2. 与国家安全、公共安全、公共卫生、重大公共利益直接相关；
3. 为应对突发公共卫生事件或紧急情况下保护自然人生命健康和财产安全所必需；
4. 在合理范围内处理您自行公开或其他已合法公开的个人信息；
5. 法律法规规定的其他情形。

（十二）其他用途
如果我们需要将个人信息用于本政策未载明的其他用途时，会事先征求您的同意。

（十三）设备权限的调用与目的
为实现相关功能并保障应用安全运行，我们可能在对应业务场景下、经您主动操作或授权后，申请开启您设备上的下列权限。我们遵循最小必要原则，不会在您未使用相关功能时提前申请或在后台静默调用：

三、我们如何使用 Cookie 和同类技术
为确保本平台正常运转、识别登录状态，我们可能在您的设备上存储必要的小数据文件（如 Cookie、登录令牌 Token 及本地缓存），通常包含标识符、系统类型等。借助其能够存储您的偏好、维持登录态。我们不会将其用于本政策所述目的之外的任何用途。您可根据偏好管理或清除本设备上保存的相关存储；大部分浏览器设有阻止 Cookie 的功能，但若您这么做，则可能需要在每次使用本平台时更改用户设置，且可能影响需登录功能的正常使用。

四、我们如何共享、转移、公开披露您的个人信息
除本政策载明的情形或法律明确规定的情形外，我们不会与其他个人信息处理者共享或转移、公开披露您的个人信息。
（一）共享
未经您的授权同意，本平台不会与其他个人信息处理者共享您的个人信息，但以下情况除外：
1. 为本平台的运营、管理与低空飞行合规，本平台可能向民用航空、军事、公安、应急管理等政府单位共享您的必要个人信息（如空域/航线申报、飞行活动管理所需）。
2. 为完成服务申请与履约所必需，向实际提供服务的第三方服务方提供办理该服务所必需的信息。
3. 本平台可能会根据法律法规规定、诉讼争议解决需要，或按行政、司法机关依法提出的要求，对外共享您的个人信息。
4. 在法律法规允许的范围内，为维护您或其他用户或社会公众利益、财产或安全免遭损害而有必要共享您的个人信息。
（二）转移
除以下情形外，我们不会将您的个人信息转移给任何其他组织和个人：
1. 在涉及合并、分立、解散、被宣告破产等原因需要转移个人信息时，我们会向您告知接收方的名称或姓名和联系方式，并要求接收方继续受本政策约束、继续履行保护义务；接收方变更原先的处理目的、处理方式时，将重新依法向您征求授权同意。
2. 法律法规规定的其他情形。
（三）公开披露
除依法或经您单独同意外，我们不会公开披露您的个人信息。

五、我们如何存储您的个人信息
（一）保存期限
除非法律法规、监管政策另有要求，我们会在达成本政策所述目的所必要的时间内保存您的个人信息，一般不短于您使用本平台服务期间及服务终止后的诉讼时效内。超出上述存储期限后，我们会对您的个人信息进行删除或匿名化处理。如我们停止服务，将及时停止收集活动，并在法律法规及监管要求的时限届满后删除存储的个人信息。
（二）存储地点
原则上，我们在中华人民共和国境内运营中收集和产生的您的个人信息，存储在中华人民共和国境内。

六、我们如何保护您的个人信息
（一）我们已采取符合业界标准、合理可行的安全防护措施保护您的个人信息，防止其遭到未经授权的访问、公开披露、使用、修改、损坏或丢失，包括但不限于：数据传输加密（HTTPS）、密码加密存储（哈希）、访问令牌（Token）鉴权、图形验证码防重放、敏感信息（姓名/证件号）脱敏展示、访问权限控制与操作日志记录。我们仅授权有必要知悉相关信息的员工、合作方在最小范围内访问个人信息，并要求其履行保密义务。
（二）您应当妥善保存登录的账号、密码等信息，由于您的原因造成账号、密码等信息泄露产生的后果由您承担。
（三）由于技术水平限制及可能存在的各种恶意手段，安全问题有可能因我们可控范围外的因素而出现。在发生信息安全事件后，我们将按照相关法律法规及监管政策的要求，及时向您告知事件基本情况、可能影响、已采取或将采取的处置措施与您可自主防范的建议；难以逐一告知时，我们会采取合理方式发布公告，并按监管部门要求主动上报处置情况。

七、未成年人信息保护
本平台提供的服务主要面向成年人。低空研学等服务可能面向未成年人（含不满十四周岁的儿童）。我们只会在法律允许、父母或其他监护人明确同意且保护儿童所必要的情况下处理合法收集到的儿童个人信息。若为不满十四周岁的未成年人报名，应由监护人陪同或经监护人同意，并按要求签署安全协议、由监护人签字。如果我们发现在未事先获得父母或其他监护人同意的情况下收集了儿童的个人信息，我们会设法尽快删除数据。
如您是儿童的父母或其他监护人，请关注您所监护的儿童是否在取得您的授权同意后使用我们的服务。如果您有理由相信儿童未经您事先同意而向本平台提交了个人信息，请联系我们以确保删除此类信息，并请保证儿童已取消相关服务。

八、您的权利
（一）查询、更正您的个人信息
您可在"个人中心/个人信息"页面查阅您的账号资料并进行更正；企业用户可按规定变更企业主体信息。您也可联系我们协助查阅、更正。
（二）删除您的个人信息
在下列情形下，您可请求删除个人信息：处理目的已实现或无法实现；我们停止提供服务；您撤回同意；我们违反法律法规或约定处理个人信息等。您可通过本政策文末联系方式提出删除请求，我们将在核实身份后于【15】个工作日内完成处理。
（三）撤回您的授权同意
对于您已授权同意我们使用的终端设备权限（如相机、相册/存储等），您可通过设备的系统设置或应用权限管理来改变或撤回授权同意；您也可通过关闭相应功能、退出登录、注销账号等方式撤回此前提供的授权同意。撤回同意不影响撤回前基于同意所进行处理的效力；撤回后您可能无法使用相应功能服务。
（四）复制您的个人信息
如您需要个人信息副本，可通过本政策文末方式联系我们，在核实您的身份后，我们将向您提供您在我们的服务中的个人信息副本，但法律法规另有规定或本政策另有约定的除外。
（五）账号找回与密码重置

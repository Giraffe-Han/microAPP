# 平台协议与隐私政策（拟稿留档）

本目录存放【低空综合服务平台】对外公示的《用户协议》与《隐私政策》拟稿，供法务/合规评审与留档。

## 文件清单

- `用户协议.md` —— 平台服务、账号、飞行合规、行为规范、费用、违约、送达、免责、争议解决等
- `隐私政策.md` —— 个人信息收集/使用/共享/存储/保护、设备权限（含相机）、未成年人、您的权利等

> 两份文件均以「浙南低空飞行服务平台」的正式协议为骨架，替换为本平台主体与服务，并补入本平台特有场景后合并而成。

## 发布方式（拟稿评审通过后）

1. 登录管理端 → **系统设置 → 协议管理**；
2. 将对应文件「正文」部分粘贴到《用户协议》/《隐私政策》文本框，填写版本号（如 `v1.0.0`）后保存；
3. 保存后即时覆盖占位内容，H5（`/agreement/user`、`/agreement/privacy`）与小程序协议页自动读取。

对应后端接口：`GET /api/agreements/:type`（公开）、`GET/POST /api/admin/agreements`（管理端）；内容存于 `servicesConfig._system.agreements`。

## 渲染限制

协议展示页为**纯文本渲染**（`white-space: pre-wrap`），保留换行与段落，但**不支持加粗/富文本**。因此正文中以 `【特别提示】` 文字标注重点条款，替代原参考稿的加粗。若需重点条款真正加粗，需另行升级协议展示页与管理端编辑器为支持简单 HTML/Markdown。
